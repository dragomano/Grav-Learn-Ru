# Переход на Grav

Как перейти на Grav с других систем управления контентом. Описаны Drupal 7 и WordPress.

## В этом разделе

- **[Переход с WordPress](from-wordpress/index.md)** — пользователи WordPress слева экспортируются в Grav справа.
