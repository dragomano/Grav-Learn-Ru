# Ошибка сервера Grav

`![](grav-server-error.png?classes=center)`

Ошибки сервера почти всегда вызваны неверной конфигурацией Grav. Что-то пошло не так, и из-за этого Grav не может восстановиться и отдать страницу.

Когда вы видите это сообщение, сервер работает в режиме `Production`, чтобы не показывать пользователям потенциально конфиденциальную информацию. Сама ошибка сохраняется в файл `logs/grav.log`. Изучите этот файл, чтобы понять точную причину.

Возможные причины:

* Ошибки сервера из-за устаревшей конфигурации
* Неверные права доступа к файлам, из-за которых Grav не может записывать данные
* Изменения в файловой системе, о которых Grav ещё не знает
* Ошибки разбора конфигурации из-за неверно оформленных файлов конфигурации

> [!NOTE] Примечание
> Если у вас установлен плагин **Grav Administration**, ошибки сервера можно просматривать оттуда. Нажимая на отдельные ошибки, вы увидите страницы отладки, даже если отладчик был выключен.

## Устаревшая конфигурация

Первое, что нужно сделать, — очистить кэш, чтобы конфигурация была актуальной:

```bash
bin/grav clearcache
```

> [!CAUTION] Внимание
> Прежде чем двигаться дальше, убедитесь, что у вас нет других проблем с правами доступа к файлам, подобных этой.
