# Шаблоны и брендирование {: #templates-and-branding }

Каждое письмо кампании, подтверждения и автоматизации рисуется в одном макете с вашим логотипом и цветами. Эта страница описывает настройки макета, шаблоны кампаний на вкладке **Templates** и переопределение шаблонов Twig Mailroom в теме.

## Макет письма {: #the-email-layout }

Вкладка **Email Design** в настройках Mailroom задаёт рамку: ваш логотип или название сайта вверху, белую карточку для сообщения и подвал со ссылками отписки.

| Настройка | Название | По умолчанию | Что делает |
|---|---|---|---|
| `branding.logo` | Logo | пусто | URL изображения или путь на этом сайте, например `/user/images/logo.png`. Пусто печатает название вашего сайта в шапке. |
| `branding.logo_width` | Logo Width (pixels) | `160` | Какой ширины рисуется логотип (от 16 до 600). Высота следует за ней. |
| `branding.accent` | Accent Color | пусто | Ссылки, кнопка подтверждения и линия под шапкой в каждом письме, а также кнопки и ссылки на публичных страницах Mailroom и в блоке подписки. Пусто — бирюзовый (`#1a6f83`) в письме, а на страницах — собственный акцент вашей темы, если он есть (у Quark2 есть), иначе бирюзовый. |
| `branding.background` | Background Color | `#f4f5f7` | На чём лежит карточка. |
| `branding.text` | Text Color | `#222222` | Цвет самого сообщения. |
| `branding.footer_text` | Footer Text | пусто | Строка или две под каждым сообщением, например почему люди его получают. Обычный текст. |
| `branding.postal_address` | Postal Address | пусто | Печатается внизу каждого сообщения, брендированного или простого, и в его текстовой части. |

Цвета — шестнадцатеричные коды (`#abc` или `#aabbcc`); всё остальное заменяется значением по умолчанию, а не печатается, поэтому опечатка не может сломать письмо.

> [!IMPORTANT] Важно
> Закон о массовых рассылках во многих странах, включая американский CAN-SPAM, ожидает настоящий почтовый адрес в маркетинговом письме. Заполните **Postal Address** до первой кампании.

### Простой макет {: #the-plain-layout }

Кампания или письмо автоматизации, установленные в **Plain**, обходятся без шапки, карточки и брендирования: белый фон и ваше сообщение, с подвалом отписки ниже. **Footer Text** и **Postal Address** всё равно печатаются под этим подвалом и в конце текстовой части каждого письма, потому что адрес ожидается в каждом сообщении.

## Шаблоны {: #templates }

Шаблон — отправная точка для кампаний: тема, прехедер, сообщение и макет, которые вы снова и снова набираете. Кампания копирует шаблон при создании и больше его не читает, поэтому изменение или удаление шаблона никогда не трогает кампании, уже написанные по нему.

На вкладке **Templates**:

1. Нажмите **New template**.
2. Дайте ему имя, тему, прехедер, сообщение и макет — те же поля, что у кампании. Теги слияния проверяются так же.
3. Оставьте **Offered when writing a campaign** отмеченным, чтобы предлагать его в редакторе кампании.
4. Сохраните. Предпросмотр рисует его через настоящий макет.

**Start a campaign from this** у шаблона открывает новую кампанию с заполненными полями. Через API передайте `template_id` при создании кампании.

## Переопределение шаблонов в вашей теме {: #override-the-templates-in-your-theme }

Шаблоны Mailroom — обычные файлы Twig. Скопируйте один в папку `templates/` вашей темы по тому же пути, и ваша копия победит.

### Шаблоны писем {: #email-templates }

| Шаблон | Что это |
|---|---|
| `emails/mailroom-email-layout.html.twig` | Брендированный макет, который расширяет каждое письмо |
| `emails/newsletter-plain-layout.html.twig` | Простой макет |
| `emails/newsletter-campaign.html.twig`, `emails/newsletter-campaign.txt.twig` | Письмо кампании или автоматизации, HTML и обычный текст |
| `emails/newsletter-confirmation.html.twig`, `emails/newsletter-confirmation.txt.twig` | Письмо подтверждения |

Макеты делят один контракт, поэтому дочерний шаблон расширяет любой из них, не зная какой:

- **Блоки**: `title`, `preheader`, `content` и `footer`, которые заполняют дочерние шаблоны; у брендированного макета также есть `header` для копии, которой нужна другая шапка без изменения остального.
- **Переменные**, которые получает каждое письмо: `subject`, `site_name`, `site_url`, `store_url` (главная страница сайта), `email_layout` и `t_prefix`. Кампания добавляет `preheader`, `content`, `campaign`, `eyebrow`, `unsubscribe_url`, `preferences_url`, `browser_url` и `plain_layout`; подтверждение добавляет `confirm_url`, `list_name` и `subscriber_email`.
- Текст подвала и почтовый адрес печатаются после блока `footer`, а не внутри него, поэтому дочерний шаблон, заменяющий подвал, всё равно их несёт.

> [!WARNING] Предупреждение
> Сохраните `emails/newsletter-campaign.txt.twig`, если переопределяете шаблоны кампании. Без текстовой части кампании уходят только в HTML, по которому спам-фильтры снижают оценку, и проверка **Plain-text part** на экране Health не проходит.

### Шаблоны страниц {: #page-templates }

Публичные страницы и блок подписки можно переопределить так же: `newsletter-confirm.html.twig`, `newsletter-unsubscribe.html.twig`, `newsletter-preferences.html.twig`, `newsletter-message.html.twig` и `partials/newsletter-signup.html.twig`. См. [Списки и формы подписки](../lists-and-signup-forms/index.md#the-public-pages).

Каждый из них включает `partials/mailroom-accent.html.twig` в своём внешнем элементе, что передаёт странице **Accent Color**, когда он задан. Сохраните include в копии или задайте цвет в таблице стилей темы:

```css
.mailroom { --mailroom-accent: #7c3aed; }
```
