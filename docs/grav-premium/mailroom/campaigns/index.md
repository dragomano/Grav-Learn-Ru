# Кампании {: #campaigns }

Кампания — одно письмо, написанное один раз и отправленное в ваши списки: тема, немного Markdown и то, кому оно идёт. Эта страница описывает редактор кампании, отправку и то, что можно делать после того, как кампания ушла.

Для написания и редактирования кампаний нужен `mailroom.manage`. Запуск, продолжение, тестовая отправка, отправка новичкам и повтор неудачных отправок также требуют `mailroom.send`.

## Вкладка Campaigns {: #the-campaigns-tab }

**Campaigns** перечисляет каждую кампанию, начиная с новых, с её состоянием, списками, в которые она идёт, числом получателей и процентами открытий и переходов. Фильтр состояния сужает список, со счётчиками по всей таблице.

| Состояние | Значение |
|---|---|
| Draft | Никуда не идёт. Редактируйте свободно. |
| Scheduled | Ждёт своего момента. Её всё ещё можно редактировать, приостановить или отменить. |
| Sending | Почта уходит сейчас. Редактировать нельзя. |
| Paused | Остановлена на середине. Продолжение идёт с места остановки. |
| Sent | Всем в аудитории отправлено. |
| Canceled | Остановлена навсегда. Запустить снова нельзя. |
| Stopped | Слишком много сообщений подряд было отклонено. Исправьте настройки почты и продолжите её. (`failed` в API) |

## Написание кампании {: #write-a-campaign }

Нажмите **Write a campaign** или **Start a campaign from this** у [шаблона](../templates-and-branding/index.md#templates), который один раз копирует поля шаблона.

| Поле | Что это |
|---|---|
| Name | Как её называет сайт. Снаружи этого никто не видит. |
| Subject | Строка темы. Может нести теги слияния. |
| Preheader | Строка, которую ящик показывает после темы. Пусто позволяет почтовому клиенту взять первые слова сообщения. |
| Message | Markdown, обёрнутый в тот же макет, что и каждое другое письмо сайта. |
| Layout | **Site branding** (ваш логотип, цвета и карточка) или **Plain** (без шапки и карточки). См. [Шаблоны и брендирование](../templates-and-branding/index.md). |

### Кому она идёт {: #who-it-goes-to }

- **Send it to**: первый список или **All lists, with a segment**, чтобы отправить всем в любом списке, кто совпадает с сегментом.
- **Also send to**: отметьте больше списков. Тот, кто находится в нескольких из них, получает одну копию.
- **Narrow it with a segment**: отправляется только людям в этих списках, которые также совпадают с сегментом. С **All lists, with a segment** сегмент обязателен.

Счётчик под выбором говорит, сколько людей получат её прямо сейчас, вычисленный так же, как при отправке: каждый человек один раз, а все исключённые, уже отсутствующие в этих списках или никогда не подтвердившие подписку не учитываются. Страница кампании потом говорит «Sent to: Newsletter, Events» (или «All lists, matching» с сегментом).

### От кого она приходит {: #who-it-comes-from }

**From name**, **From address** и **Reply-to**. Оставьте их пустыми, чтобы использовать значения по умолчанию с вкладки **Sending** Mailroom; редактор говорит, откуда берётся каждое значение («from Mailroom settings», «from the Email plugin»).

### Подсчёт и разметка ссылок {: #counting-and-link-tagging }

- **Count opens** и **Count clicks** решают, несёт ли эта кампания пиксель открытия и отправляет ли ссылки через редирект перехода (см. [Отчёты и отслеживание](../reports-and-tracking/index.md)).
- **How links are tagged** переопределяет UTM-значения сайта для ссылок этой кампании обратно на ваш сайт. Оставьте поле пустым, чтобы использовать значение сайта по умолчанию.

Новая кампания начинает с **Count opens** и **Count clicks**, выставленных так, как настроены **Track Opens** и **Track Clicks** на вкладке **Tracking**, и каждая кампания может сказать иначе.

## Теги слияния {: #merge-tags }

Теги слияния заполняются для каждого человека. Пишите их в теме, прехедере или сообщении:

| Тег | Чем становится |
|---|---|
| `{{ subscriber.name }}` | Его имя |
| `{{ subscriber.first_name }}` | Первое слово его имени |
| `{{ subscriber.email }}` | Его адрес |
| `{{ site.name }}` | Заголовок вашего сайта (`site.title`) |
| `{{ site.url }}` | Адрес вашего сайта |
| `{{ campaign.name }}` | Название кампании |
| `{{ unsubscribe_url }}` | Его ссылка отписки |
| `{{ preferences_url }}` | Его ссылка на центр предпочтений |
| `{{ browser_url }}` | Кампания в браузере |

`{{ store.name }}` и `{{ store.url }}` тоже работают и дают те же значения, что `site.*`. Имя есть не у всех, поэтому давайте запасное значение:

```twig
Hello {{ subscriber.first_name|default('there') }},
```

Всё остальное отклоняется при сохранении с указанием переменной, поэтому опечатка никогда не дойдёт до ящика. Панель **Merge tags you can use** в редакторе перечисляет их.

## Тест двух тем {: #test-two-subjects }

Отметьте **Test two subjects** и напишите **The other subject**. Часть аудитории получает одну тему, часть — другую, а все остальные получают ту, что показала себя лучше. Отличается только тема.

- **How much of the list is tested**: от 10 до 50 процентов (по умолчанию 20).
- **How long to wait before the winner goes out**: 1, 2, 4, 8 или 24 часа (по умолчанию 4), считая с момента запуска кампании.

Редактор проговаривает это: «N people get one of the two subjects now; the other N get the winner at ...». Победитель — тема, которую открыло больше людей; в кампании без подсчёта открытий — та, по которой больше перешли, а при равенстве — первая тема. Страница кампании показывает обе темы с их собственными счётчиками отправленных, открывших и перешедших и говорит, какая победила.

## Предпросмотр и тест {: #preview-and-test }

Сохраните кампанию, и панель **Preview** нарисует её через настоящий макет с примером подписчика, с **Plain text part** ниже. Отслеживание в предпросмотре выключено, поэтому ничего не считается.

**Send a test** отправляет одну копию на указанный вами адрес с `[Test]` перед темой. Ничего не считается. Посмотрите её в настоящем ящике, прежде чем отправлять кому-то ещё. Тестовая отправка записывает строку тестового адреса, поэтому ссылка отписки в ней указывает на кого-то; тестовые адреса исключены из каждой таблицы и аудитории.

## Отправка или планирование {: #send-or-schedule }

- **Send it now**: спрашивает «Send this to N people?», и почта начинает уходить, как только её заберёт обработчик.
- **Schedule it**: выберите **Send at**, затем подтвердите. Она ждёт в очереди до этого времени, и её всё ещё можно редактировать, приостановить или отменить.

Кампаниям нужен обработчик (см. [Задания и cron](../jobs-and-cron/index.md)). Обработчик отправляет со скоростью **Messages Per Minute** по всем кампаниям, порцией по **Recipients Per Run** за раз.

Согласие проверяется снова при сборке каждого сообщения, поэтому тому, кто ушёл или был исключён после запуска кампании, не пишут.

## Пока она отправляется {: #while-it-sends }

| Кнопка | Что делает |
|---|---|
| **Pause** | Отправка останавливается в пределах одного сообщения. Продолжение идёт с места остановки, и никому не пишут дважды. |
| **Resume** | Продолжает приостановленную или остановленную кампанию. |
| **Cancel it** | Останавливает её навсегда. У кого она уже есть, тот её сохраняет. Предлагается для запланированной, отправляющейся, приостановленной или остановленной кампании; у черновика вместо неё **Delete**. |

После **Stop After Consecutive Failures** отклонённых отправок подряд (25) кампания останавливается сама, и баннер на панели управления говорит об этом. Исправьте настройки почты, затем нажмите **Resume**.

**Keep it up to date** заново загружает кампанию каждые тридцать секунд, пока открыт её экран.

## После отправки {: #after-it-went-out }

Страница кампании показывает:

- цифры: кому отправлено, доставлено (или **Accepted**, что взял транспорт, когда ни один провайдер не сообщает о доставке), открыто, переходов, возвратов, ошибок, отписок, с процентами открытий и переходов;
- **The first 48 hours**: накопительно по часам с первого сообщения;
- **Links**: каждую ссылку с её переходами;
- **Recipients**: всех, кому ушло, с тем, что произошло с каждым.

У отправленной кампании появляются ещё две кнопки:

- **Send to newcomers**: люди, присоединившиеся к её спискам после отправки (и совпадающие с её сегментом), которые её никогда не получали. «N people joined after this went out and never received it. Send it to them now?» Никто не получает вторую копию, и она остаётся одной кампанией с одним отчётом. Тест темы, у которого уже есть победитель, отправляет победителя.
- **Retry failed (N)**: снова отправляет сообщения, которые отклонил транспорт (обычно транспорт, к которому на мгновение не удалось подключиться). Возвраты и жалобы никогда не повторяются, а согласие и исключение проверяются снова. Одну неудачную отправку можно повторить из списка получателей кнопкой **Retry**.

Удалить можно только черновик или отменённую кампанию; всё, что она записала, уходит вместе с ней.

## Отписка из кампании {: #unsubscribing-from-a-campaign }

Ссылка отписки и кнопка отписки почтового клиента убирают человека из тех списков кампании, в которых он состоит, и не трогают остальные его списки. См. [Отписку и предпочтения](../unsubscribe-and-preferences/index.md).
