# Grav Premium

**Grav Premium** — растущая коллекция коммерческих плагинов и тем, которые создаёт и поддерживает команда Grav. Каждая премиальная продажа финансирует дальнейшую разработку самого Grav, а каждый продукт покрыт [лицензией Grav Premium](https://getgrav.org/premium/license).

В этой главе описаны премиальные продукты, ориентированные на **Grav 2.0**. Продукты, документация которых ещё не переписана под 2.0, показаны здесь из [главы Grav Premium для 1.7](https://learn.getgrav.org/17/grav-premium), поэтому несколько страниц всё ещё описывают классическую админку.

> [!IMPORTANT] Важно
> Для премиальных продуктов требуется бесплатный плагин **License Manager**. Установите его и добавьте лицензию продукта перед установкой самого продукта.

## Просмотр и покупка

Полный каталог с ценами, скриншотами и разбором фич находится на [getgrav.org/premium](https://getgrav.org/premium). После покупки вы попадаете на [портал лицензий Grav](https://licensing.getgrav.org/portal), где можете просмотреть каждую лицензию своей учётной записи и управлять ею. Та же ссылка есть в письме с подтверждением покупки.

## Получение помощи

Поддержка премиальных продуктов ведётся через репозиторий [grav-premium-issues](https://github.com/getgrav/grav-premium-issues) на GitHub, где у каждого продукта есть своя метка. По общим вопросам обычно быстрее ответят в [Grav Discord](https://chat.getgrav.org).
