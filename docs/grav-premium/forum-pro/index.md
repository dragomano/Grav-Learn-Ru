# Forum Pro

**Forum Pro** — полноценная платформа для обсуждений, которая работает на вашем сайте Grav и не требует внешнего хостинга. Это не iframe, не виджет стороннего сервиса и не подписка. Страницы форума — обычные страницы Grav: они наследуют вашу тему, доступны по любому выбранному маршруту, индексируются поисковыми системами, а каждое сообщение хранится в базе данных, которой владеете вы.

> [!IMPORTANT] Важно
> Для премиальных продуктов требуется бесплатный плагин [License Manager](https://getgrav.org/premium/license-manager). Установите его и добавьте лицензию продукта перед установкой Forum Pro.

## Требования {: #requirements }

| Требование | Примечания |
|---|---|
| **Grav** `>= 2.0.0-rc.8` | Forum Pro несовместим с Grav 1.7 |
| **PHP** `>= 8.3` | Проверено на 8.3 и 8.4 |
| **Плагин API** `>= 1.0.0-rc.8` | Обеспечивает интеграцию с Admin Next |
| **База данных** | SQLite (работает без настройки по умолчанию), MySQL 8+ / MariaDB 10.6+ или PostgreSQL 14+ |

Некоторые необязательные плагины расширяют возможности:

| Плагин | Что добавляет |
|---|---|
| `email` | Отправка уведомлений и дайджестов |
| `sync` + `sync-mercure` | Обновления в реальном времени, присутствие и индикаторы набора текста |
| `ai-pro` | Ежечасная проверка спама с помощью ИИ |
| `yetisearch-pro` | Нечёткий поиск с настраиваемой релевантностью |
| `codesh` | Подсветка синтаксиса на стороне сервера в блоках кода |
| `form` | Невидимая капча с проверкой proof-of-work при регистрации и входе |

Ни один из них не обязателен. Forum Pro корректно работает и без них: без `sync` форум отображается на сервере обычным образом, без `codesh` блоки кода выводятся без подсветки и так далее.

## Что входит в комплект {: #what-s-in-the-box }

- **Обсуждения** с разделами, категориями, темами, ветками ответов, Markdown с @упоминаниями и цитатами, вложениями, реакциями, опросами, метками, принятыми ответами, закладками и полной историей изменений.
- **Собственная система участников** с регистрацией, подтверждением электронной почты, сбросом пароля, профилями, аватарами, рангами, значками, группами, званиями и списком участников. Учётные записи Grav подключаются автоматически.
- **Модерация** через роли модераторов с ограниченными правами, очередь проверки на самом форуме, массовую очередь в админке, предмодерацию по категориям, жалобы участников, блокировки с апелляциями и управлением контентом, журнал аудита и ежедневный дайджест.
- **Защита от спама** в три независимых этапа (эвристики, необязательный локальный ML-классификатор, необязательная ежечасная проверка ИИ), а также ограничения для новых учётных записей и невидимая captcha.
- **Уведомления** через колокольчик в интерфейсе с всплывающими сообщениями, уровни отслеживания для тем и разделов, а также письма, повторяющие уведомления колокольчика, с немедленной, ежедневной или еженедельной доставкой.
- **Личные сообщения** между участниками, один на один или в группах, с архивированием, блокировкой, массовой очисткой и отправкой жалоб.
- **Поиск** по опубликованным сообщениям с учётом прав доступа — через встроенный движок или YetiSearch Pro.
- **Обновления в реальном времени** через плагин `sync`, с push-уведомлениями Mercure или автоматическим переходом на опрос сервера.
- **Комментарии к статьям**, которые превращают любую страницу Grav в статью с комментариями, привязанную к реальной теме форума.
- **Импорт из Discourse и XenForo**, который переносит участников (с рабочими паролями), контент, историю и файлы одной командой.

## С чего начать {: #where-to-start }

1. [Установка](installation/index.md) запускает форум, помогает выбрать базу данных и подключить его по нужному маршруту.
2. [Конфигурация](configuration/index.md) содержит полный справочник по всем блокам настроек.
3. [Администрирование](administration/index.md) проводит по разделу Forum в Admin Next.

Если вы переносите существующее сообщество, перед началом прочитайте [Миграцию из Discourse](discourse-import/index.md) или [Миграцию из XenForo](xenforo-import/index.md). Импорт можно запускать повторно, но планировать переключение проще до начала, чем после.
