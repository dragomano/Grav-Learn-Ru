# Конфигурация {: #configuration }

Эта страница перечисляет каждую настройку Helpdesk Pro, сгруппированную по вкладке, на которой она находится. Настройки лежат в `user/config/plugins/helpdesk-pro.yaml`, и почти все их можно редактировать на странице настроек плагина в Admin Next (кнопка **Settings** над рабочей областью открывает её). Значения по умолчанию поставляются в собственном `helpdesk-pro.yaml` плагина.

Секреты (секреты webhook, пароль IMAP, секрет S3, ключ API встраивания) никогда не отправляются браузеру ни одним эндпоинтом Helpdesk Pro. Где настройка принимает секрет, можно написать `env:NAME`, чтобы прочитать его из переменной окружения.

Некоторые вещи вообще не настройки: проекты, статусы, метки, пользовательские поля, правила, политики SLA и каналы уведомлений настраиваются в рабочей области и хранятся в базе данных.

## Карта вкладок {: #tab-map }

| Вкладка | Что управляет |
|---|---|
| Desk | Первый экран рабочей области, виджет панели управления, доски |
| Portal & Access | Маршрут справочного центра, гостевые обращения, защита от спама, ссылки для входа |
| Email & Notifications | Исходящая почта, вид каждого письма, уведомления сотрудникам, входящая почта, IMAP, адреса ответа |
| Attachments | Ограничения загрузки, разрешённые типы, очистка, приватный бакет |
| Search | Синонимы, исправление опечаток, подсказки, семантический поиск |
| Live Updates | Обновления в реальном времени и присутствие |
| Advanced | База данных и фоновые задания |
| Help Center | Строка навигации портала, описания и значки тем |
| Rules | Правила включены или выключены, и встроенное автоматическое закрытие |
| SLA | Часы SLA и время предупреждения |
| Ratings | Оценки клиентов |
| Client Organizations | Дополнительные заблокированные домены электронной почты |
| Channels | Доставка в каналы уведомлений |

Два ключа только для YAML: `privacy.ip_hashing` и `jobs.catch_up_exclude`. `enabled` — переключатель состояния плагина над вкладками.

## Общие {: #general }

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `enabled` | `true` | Включает плагин. |
| `privacy.ip_hashing` | `true` | Helpdesk Pro запоминает IP-адрес, с которого человека видели последним, чтобы сотрудники могли замечать злоупотребления. Когда включено, хранится только хеш SHA-256; когда выключено — сам адрес. |

## Рабочая область {: #desk }

См. [Рабочую область сотрудников](../the-desk/index.md).

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `desk.default_view` | `my-work` | Экран, на котором открывается рабочая область: `my-work` или `tickets`. |
| `admin2.dashboard` | `true` | Виджет Helpdesk на панели управления Admin Next. |
| `desk.staff_groups` | `[]` | Группы Grav, в которых состоит каждая учётная запись сотрудника (Staff Groups, выбираются из групп сайта). Сотрудника добавляют при следующем использовании рабочей области, и группы только добавляются, никогда не удаляются. Несуществующая группа пропускается. Клиенты получают `portal.client_groups` так же. |
| `desk.board` | `true` | Доски для проектов, у которых включена настройка доски. `false` скрывает все доски, а маршрут доски отвечает 404. |

У сочетаний клавиш нет настройки сайта: каждый человек выключает или включает их для своего браузера в листе сочетаний (нажмите `?` в рабочей области).

## Portal & Access {: #portal-access }

См. [Справочный центр и портал](../help-center-and-portal/index.md), [Форму запроса и гостей](../request-form/index.md) и [Ссылки для входа](../sign-in-links/index.md).

|---|---|---|

| `portal.guest_submissions` | `true` | Могут ли гости отправлять форму обращения. Только проекты `public` принимают гостевые обращения. |
| `portal.client_groups` | `[]` | Группы Grav, в которых состоит каждая учётная запись клиента. Клиента добавляют при входе или открытии справочного центра, и группы только добавляются, никогда не удаляются. Несуществующая группа или группа, дающая доступ к админке или рабочей области, пропускается. См. [Справочный центр и портал](../help-center-and-portal/index.md). |
| `portal.client_store_groups` | `[]` | Группы покупателей KahunaCart, в которых состоит покупатель магазина, пока он клиент службы поддержки (Client Store Groups, выбираются из групп покупателей KahunaCart; настройка появляется, только когда KahunaCart установлен и включён). Выдаются на лету и никогда не сохраняются: исчезают, когда человека отвязывают, блокируют или удаляют, а также когда вы убираете группу из списка. Сотрудники их никогда не получают. Группа покупателей также даёт групповые цены, скидки и доступ к страницам. См. [Справочный центр и портал](../help-center-and-portal/index.md). |
| `portal.captcha` | `cap` | `none`, `cap`, `turnstile` или `recaptcha`: провайдеры капчи плагина Form. |
| `portal.captcha_signed_in` | `false` | Спрашивать капчу и у вошедших клиентов. |
| `portal.min_submit_seconds` | `3` | Гостевое обращение, отправленное раньше этого времени после открытия формы, получает баллы спама. |
| `portal.limits.ip_per_hour` | `5` | Гостевых обращений с одного IP-адреса в час. `0` отключает ограничение. |
| `portal.limits.email_per_hour` | `5` | Гостевых обращений с одного адреса электронной почты в час. |
| `portal.limits.guest_per_hour` | `60` | Гостевых обращений от всех вместе в час. |
| `portal.magic_links` | `true` | Клиенты входят по присланной ссылке, а письма клиентам открывают обращение уже с выполненным входом. |
| `portal.magic_link_minutes` | `30` | Сколько работает ссылка для входа, запрошенная человеком. |
| `portal.email_link_days` | `7` | Сколько работает ссылка внутри письма клиенту. |

| `search.semantic.enabled` | `false` | Ранжировать по смыслу, а также по словам. |
| `search.semantic.provider` | `openai_compatible` | Любой OpenAI-совместимый API встраивания. |
| `search.semantic.base_url` | пусто (`https://api.openai.com/v1`) | Базовый URL API. |
| `search.semantic.api_key` | пусто | Ключ или `env:NAME`. |

| `search.semantic.notes` | `false` | Также встраивать внутренние заметки (отправляет текст заметок в API). |

| `jobs.catch_up_exclude` | `[search.embed]` | Типы заданий, которые догоняющая обработка никогда не выполняет. Только YAML. |
| `jobs.job_timeout_seconds` | `120` | Задание, работающее дольше, завершается ошибкой и повторяется. `0` отключает ограничение. |
| `jobs.retention_days` | `30` | Завершённые и отменённые задания и строки отправленной почты удаляются через столько дней. |
