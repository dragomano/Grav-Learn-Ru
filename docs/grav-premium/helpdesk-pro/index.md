# Helpdesk Pro {: #helpdesk-pro }

**Helpdesk Pro** — служба поддержки и система учёта заявок, которая работает внутри вашего сайта Grav. Сотрудники обрабатывают заявки в рабочей области Admin Next, клиенты следят за своими обращениями в портале на вашем сайте (обычно по адресу `/help`), а справочные статьи — обычные страницы Grav, которые портал ищет ещё до того, как кто-то напишет обращение. Всё хранится в одном файле SQLite, которым владеете вы.

> [!IMPORTANT] Важно
> Для премиальных продуктов требуется бесплатный плагин [License Manager](https://getgrav.org/premium/license-manager). Установите его и добавьте лицензию продукта перед установкой Helpdesk Pro.

## Требования {: #requirements }

| Требование | Примечания |
|---|---|
| **Grav** `>= 2.0.0` | Helpdesk Pro несовместим с Grav 1.7 |
| **PHP** `>= 8.3` | С расширениями `pdo_sqlite`, `sqlite3`, `mbstring` и `dom` |
| **Плагин API** `>= 1.0.0` | Обеспечивает работу рабочей области в Admin Next и REST API |
| **Плагин Login** `>= 3.9.0` | Учётные записи клиентов и сотрудников |
| **Плагин Email** `>= 5.2.0` | Вся исходящая почта. Для приёма писем нужна версия 5.3.0 или новее |
| **Плагин Form** `>= 9.0.0` | Капча формы запроса |
| **Admin Next** | Где работают сотрудники. Им нужно право `api.access` |

База данных только SQLite, и она поставляется вместе с плагином: не нужно настраивать сервер базы данных, вариантов MySQL или PostgreSQL нет.

Необязательные плагины добавляют возможности:

| Плагин | Что добавляет |
|---|---|
| `sync` | Обновления в рабочей области и портале без перезагрузки |
| `sync-mercure` (1.2.2 или новее) или `sync-ably` | Мгновенная push-доставка обновлений вместо опроса сервера |
| `yetisearch-pro` | Общие настройки семантического поиска, если он используется в обоих продуктах |

Helpdesk Pro работает и без них. Без `sync` экраны обновляются при возвращении к ним, а не в реальном времени.

## Что входит в комплект {: #what-s-in-the-box }

- **Рабочая область сотрудников** в Admin Next: «Моя работа», «Все заявки» с чипами фильтров, доски, сортировка, ответы и внутренние заметки, сохранённые ответы и макросы, сохранённые представления, массовое редактирование и сочетания клавиш.
- **Клиентский портал**, где клиенты входят по ссылке из письма (пароль не нужен), следят за своими обращениями, отвечают, отмечают заявку решённой и открывают её снова. Гости тоже могут отправлять обращения — за капчей, ограничениями частоты и оценкой спама.
- **База знаний** из страниц Grav с поиском, карточками тем, вопросом «Было ли это полезно?» и подсказками, пока человек вводит текст обращения.
- **Почта в обе стороны**: фирменные письма клиентам, которые правильно собираются в цепочки, ответы по почте от клиентов и сотрудников, новые заявки по почте через webhook провайдера или почтовый ящик IMAP.
- **Уведомления** в колокольчике с письмом как запасным вариантом для непрочитанного, ежедневным дайджестом и командными каналами для Slack, Discord, подписанного webhook или командного ящика.
- **Автоматизация**: правила «когда/если/тогда», встроенное автоматическое закрытие и цели SLA с рабочими часами, предупреждениями и нарушениями.
- **Оценки клиентов**, **пользовательские поля**, **организации**, которые делят обращения между коллегами, и **отчёты** с экспортом в CSV.
- **Инструменты конфиденциальности**: сводка по субъекту данных для каждого человека, объединение, юридические удержания и два режима удаления.
- **REST API и инструменты MCP**, чтобы скрипты и ИИ-клиенты могли делать то же, что рабочая область, а также **события** для дополнений.

## С чего начать {: #where-to-start }

1. [Установка](installation/index.md) запускает плагин, защищает базу данных и настраивает cron.
2. [Начало работы](getting-started/index.md) проводит по странице справочного центра, первому проекту и первой заявке, а также объясняет термины Helpdesk Pro.
3. [Рабочая область сотрудников](the-desk/index.md) — экскурсия по месту, где сотрудники проводят свой день.

Когда будете готовы принимать почту, прочитайте [Исходящую почту](outbound-email/index.md), а затем [Входящую почту](inbound-email/index.md). Если что-то не происходит (нет писем, нет дайджестов, правила не срабатывают), начните с разделов [Устранение неполадок](troubleshooting/index.md) и [Задания и cron](jobs-and-cron/index.md).
