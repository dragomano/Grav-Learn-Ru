# License Manager

## Перед началом

Прежде чем устанавливать премиальный плагин, необходимо установить плагин `License Manager`. Это бесплатный плагин, доступный в GPM; его можно установить как любой другой — через раздел **Plugin** в плагине admin или из командной строки.

```
$ bin/gpm install license-manager
```

После установки нужно добавить лицензию продукта. Она приходит по электронной почте при покупке продукта. Если вы потеряли лицензию, её можно получить в новом [портале лицензий](https://licensing.getgrav.org/portal). Используйте тот же адрес электронной почты, который применялся при покупке продукта.

### Установка лицензии

После установки плагина `License Manager` можно добавить лицензию. Это можно сделать двумя способами:

##### Через плагин Admin

1. Перейдите в раздел **License Manager** в плагине admin.
2. Нажмите кнопку **Install License**.
3. Введите лицензионный ключ и нажмите **Install**.
4. Появится сообщение об успехе, и лицензия будет установлена.

##### Из командной строки

Лицензию можно также установить из командной строки. Для этого выполните следующую команду:

```
$ bin/plugin license-manager add -s <product-slug> -l <license-key>
```
