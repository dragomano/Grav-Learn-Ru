# Справочник REST API

## Базовый URL

Все эндпоинты имеют префикс: `{site_url}/api/v1`

## Аутентификация

Публичные эндпоинты, не требующие аутентификации, — это всё под `/auth/` (токен, проверка 2FA, обновление, отзыв, восстановление и сброс пароля, настройка, принятие приглашения, политика паролей, капча и SSO), `GET /translations/{lang}`, `GET /thumbnails/{file}` и `GET /ping`. Плагины могут добавлять собственные публичные маршруты через событие `onApiCollectPublicRoutes`. Всё остальное требует аутентификации через:

- **ключ API** (заголовок `X-API-Key` или параметр запроса `?api_key=`),
- **JWT-токен доступа** (предпочтительно как `X-API-Token`, принимается и как `Authorization: Bearer`), или
- активную **сессию Grav** (проброс).

Подробности, включая причины, по которым `X-API-Token` предпочтительнее `Authorization: Bearer` на хостах FastCGI / PHP-FPM, см. в разделе [Аутентификация](../authentication/index.md).

## Окружения

API учитывает окружения Grav. Передайте `X-Grav-Environment: <hostname>`, чтобы использовать конфигурацию конкретного окружения.

## Общие коды ответов

| Код | Описание |
|------|-------------|
| 200 | Успех |
| 201 | Создано |
| 204 | Нет содержимого (успешное удаление) |
| 304 | Не изменено (совпадение ETag при условном GET) |
| 400 | Неверный запрос |
| 401 | Не авторизован |
| 403 | Запрещено |
| 404 | Не найдено |
| 405 | Метод не разрешён (путь существует, но не для этого метода) |
| 409 | Конфликт (в том числе ETag в `If-Match`, который больше не совпадает при обновлении) |
| 422 | Ошибка валидации |
| 429 | Превышено ограничение частоты запросов |
| 500 | Внутренняя ошибка сервера |
| 502 | Плохой шлюз (например, недоступен репозиторий GPM, не прошёл тест вебхука) |
