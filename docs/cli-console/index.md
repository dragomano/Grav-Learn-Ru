# Консоль CLI

Grav дружелюбен к разработчикам и предоставляет множество полезных инструментов командной строки и фич, чтобы всё было как можно проще и удобнее для скриптов.

## В этом разделе

- **[Введение в командную строку](command-line-intro/index.md)** — Ни для кого не секрет, что Grav создавался с расчётом на командную строку. Плагин Admin, безусловно, упрощает решение многих задач без открытия терминала (MacOS и Linux) или командной строки (Windows), но…
- **[Команда Grav](grav-cli/index.md)** — Grav поставляется со встроенным интерфейсом командной строки (CLI), который находится в bin/grav. CLI крайне полезен для выполнения повторяющихся задач, таких как очистка кэша, создание резервных копий и многого другого.
- **[Команда Plugin](grav-cli-plugin/index.md)** — Плагины могут интегрироваться в CLI Grav bin/plugin и расширять функциональность плагинов через терминал, выполняя определённые задачи.
- **[Команда GPM](grav-cli-gpm/index.md)** — Начиная с версии 0.9.3 Grav включает GPM (менеджер пакетов Grav), который позволяет устанавливать, обновлять, удалять и перечислять все темы и плагины, доступные в репозитории Grav, а также обновлять сам Grav…
- **[Скриптовые обновления](scripted-upgrades/index.md)** — Или: обновление нескольких установок Grav одновременно.
