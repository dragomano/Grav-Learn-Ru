# Рецепты

В этой главе собраны практические рецепты в формате «задача — решение» для Grav 2.0 и интерфейса Admin2. В каждом рецепте сформулирована проблема и разобран рабочий вариант решения, который можно адаптировать под себя.

Рецепты здесь рассчитаны на актуальное поколение Grav: REST API, SPA Admin2 и события интеграции плагинов. Рецепты, которые опираются на устаревший интерфейс admin-classic, см. в [рецептах для Grav 1.7](https://learn.getgrav.org/17/cookbook).

## В этом разделе

- **[Общие рецепты](general-recipes/index.md)** — Сборник задач и их решений, связанных с Grav в целом.
- **[Рецепты Twig](twig-recipes/index.md)** — Сборник задач и их решений, связанных с шаблонизатором Twig.
- **[Рецепты плагинов](plugin-recipes/index.md)** — Сборник задач и их решений, связанных с плагинами Grav.
- **[Рецепты для админки](admin-recipes/index.md)** — Задачи и решения по настройке интерфейса Admin2. Admin2 — одностраничное приложение на SvelteKit, которое общается с вашим сайтом через REST API; плагины расширяют его, подписываясь на события `onApi*` и при необходимости поставляя небольшие веб-компоненты.
- **[Уроки](tutorials/index.md)** — В этом разделе собраны пошаговые уроки для типовых сценариев. Не стесняйтесь редактировать эти страницы и добавлять свои.
