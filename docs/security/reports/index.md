# Отчёты

GitHub теперь поддерживает уведомления о безопасности для каждого репозитория, поэтому здесь вы найдёте актуальные отчёты и политики. Подробности всегда можно найти в [программе CVE](https://cve.mitre.org/cgi-bin/cvekey.cgi?keyword=Grav) от MITRE, а обзор — на [CVE Details](https://www.cvedetails.com/vulnerability-list.php?vendor_id=20511&order=1&trc=9&sha=2d99a894afce93a4722e6f89c4baddfb1a6c010f).

Важнее всего, что Grav и плагин Admin — основа, на которой строятся все остальные расширения, поэтому за их уведомлениями и политиками следить важнее всего:

- Ядро Grav: [уведомления о безопасности](https://github.com/getgrav/grav/security/advisories) и [политика безопасности](https://github.com/getgrav/grav/security/policy)
- Admin: [уведомления о безопасности](https://github.com/getgrav/grav-plugin-admin/security/advisories) и [политика безопасности](https://github.com/getgrav/grav-plugin-admin/security/policy)
