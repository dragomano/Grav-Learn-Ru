# Структура папок {: #folder-structure }

Поскольку Grav — это **файловая CMS**, то есть в её основе нет базы данных, структура папок вашего сайта очень важна. На **верхнем уровне** установки Grav структура папок выглядит так:

```bash linenums="1"
/assets
/backup
/bin
/cache
/images
/logs
/system
/tmp
/vendor
/user
```

Давайте копнём немного глубже в каждую из этих папок верхнего уровня и объясним, для чего они нужны:

### /assets

Папка `assets` используется новой системой управления ресурсами внутри Grav для хранения обработанных файлов `.css` и `.js`.

> [!CAUTION] Внимание
> Эту папку не следует использовать для хранения пользовательских данных, так как её содержимое регулярно очищается полностью.

### /backup

Папка `backup` — место по умолчанию для резервных копий Grav.

### /bin

Папка `bin` содержит [приложение Grav CLI](../../cli-console/grav-cli/index.md), которое можно использовать для выполнения некоторых полезных задач из командной строки. Это довольно продвинутая фича, в первую очередь предназначенная для разработчиков, поэтому отложим эту тему на потом.

### /cache

Папка `cache` используется для хранения временных кэшированных файлов, которые Grav автоматически создаёт для повышения производительности. По умолчанию Grav управляет кэшированием автоматически, выбирая лучший доступный вариант для вашего хостингового окружения, чтобы сайт работал как можно быстрее.

Если Grav решает, что **файловая система** — лучший способ кэширования, сгенерированные кэшированные файлы будут храниться здесь. Шаблонизатор Twig также использует это место для хранения своих предварительно скомпилированных файлов шаблонов. Опять же, это делается для того, чтобы Grav работал на оптимальной скорости.

> [!CAUTION] Внимание
> Эту папку не следует использовать для хранения пользовательских данных, так как её содержимое регулярно очищается полностью.

### /images

Grav поставляется со встроенной мощной и при этом очень [простой в использовании библиотекой обработки изображений](../../content/media/index.md). Это значит, что вы можете легко изменять размер изображения на лету из своего контента или даже из плагина. Эти изображения хранятся в папке `images`, чтобы их можно было повторно использовать, если то же изображение с тем же размером запросят снова.

Эта папка действует как кэш изображений и предназначена для автоматически генерируемых файлов. Медиафайлы, предоставленные пользователем, следует хранить в папке `user/pages/`, `user/themes/` или даже в собственной папке `user/images/`.

> [!CAUTION] Внимание
> Эту папку не следует использовать для хранения пользовательских данных, так как её содержимое регулярно очищается полностью.

### /logs

Когда Grav обнаруживает ошибку или если у вас включено дополнительное журналирование или профилирование, он сохраняет соответствующие файлы журналов в папке `logs`.

### /system

Папка `system` — это место, где находятся файлы, которые обеспечивают работу Grav. Вам не следует редактировать что-либо в этой папке, потому что обновление Grav может перезаписать ваши изменения. Если нужно изменить что-то, связанное с работой Grav, используйте плагины, как обсуждается в следующих главах.

### /tmp

Папка `tmp` используется Grav и плагинами для хранения временных файлов.

> [!CAUTION] Внимание
> Эту папку не следует использовать для хранения пользовательских данных, так как её содержимое регулярно очищается полностью.

### /vendor

Папка `vendor` содержит важные библиотеки, на которые опирается Grav. Она похожа на папку `system` тем, что её содержимое не следует редактировать, если вы не абсолютно уверены в том, что делаете.

Если вы [устанавливали](../installation/index.md) Grav с GitHub, папка `vendor` не была установлена вместе с ним. Чтобы создать и наполнить папку vendor, вам нужно выполнить `bin/grav install` или `composer install` из корня вашей установки Grav. Подробности можно найти в разделе [Установка](../installation/index.md).

### /user

Это самая важная папка для большинства пользователей Grav. Именно здесь вы будете проводить время, создавая контент, используя плагины и редактируя темы. Давайте заглянем немного глубже в эту папку:

```bash linenums="1"
/user/accounts
/user/blueprints
/user/config
/user/data
/user/images
/user/languages
/user/pages
/user/plugins
/user/themes
```

### /user/accounts {: #user-accounts }

Папка `accounts` — это место, где вы будете определять учётные записи пользователей, если требуется ограничить доступ к определённым частям сайта.

### /user/blueprints {: #user-blueprints }

Папка `blueprints` содержит ваши собственные схемы для сайта.

### /user/config {: #user-config }

[Файлы в папке config](../grav-configuration/index.md) используются для настройки сайта и обсуждались в предыдущей главе.

### /user/data {: #user-data }

Папку `data` плагины могут использовать для хранения данных, к которым вы сможете обратиться позже. Хороший пример плагина, использующего эту папку, — плагин **Forms**, который может принимать веб-форму и сохранять отправленные данные в текстовый файл в этой папке. Здесь также можно хранить другие вещи, например пользовательские загрузки или что угодно ещё.

> [!CAUTION] Внимание
> По умолчанию эта папка недоступна через браузер.

### /user/images {: #user-images }

Папку `images` можно использовать для хранения ваших изображений. Доступ к ней осуществляется через поток `image://`.

### /user/languages {: #user-languages }

Папка `languages` содержит [переопределения переводов](../../content/multi-language/index.md#translation-overrides).

### /user/pages {: #user-pages }

Это сердце Grav. Папка `pages` — это место, где вы создаёте и редактируете контент. Мы гораздо подробнее рассмотрим это в [следующей главе](../../content/index.md).

### /user/plugins {: #user-plugins }

Плагин может расширять быстрое ядро Grav определёнными фичами, которые могут вам понадобиться для вашего сайта. Плагины можно скачать с [GetGrav.org/downloads/plugins](https://getgrav.org/downloads/plugins) или [разработать собственные](../../plugins/plugin-tutorial/index.md).

### /user/themes {: #user-themes }

Тема превращает ваш контент в настоящий сайт. Она преобразует созданный вами контент в HTML, который понимает браузер и отображает вашей аудитории. Вместе с Grav поставляется базовая тема, но вы также можете скачать другие с [GetGrav.org/downloads/themes](https://getgrav.org/downloads/themes) или даже создать свою. Глава [Темы](../../plugins/index.md) расскажет об этом подробнее.
