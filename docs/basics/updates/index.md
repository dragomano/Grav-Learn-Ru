# Обновление Grav и плагинов {: #updating-grav-plugins }

Предпочтительный способ поддерживать Grav, плагины и темы в актуальном состоянии — использовать **GPM (менеджер пакетов Grav)**. Полную информацию можно найти в [документации GPM](../../cli-console/grav-cli-gpm/index.md).

Мы также встроили **GPM** в наш плагин [Admin Panel](../../admin-panel/index.md), который будет проверять, предлагать и автоматически устанавливать любые обновления.

### Какая у меня версия? {: #which-version-do-i-have }

Есть несколько способов узнать, какая версия Grav и плагинов используется на сайте:

* **Панель администрирования**: версия Grav отображается внизу боковой панели. Версии плагинов и тем перечислены в их собственных разделах.
* **CLI**: выполните команду `bin/gpm version grav`. Чтобы получить список версий тем и плагинов, перечислите их по именам.
* **Файловая система**: проще всего узнать версию, посмотрев файл `CHANGELOG.md` в корне установки Grav. То же верно для плагинов и тем — обычно они находятся в папках `user/plugins` и `user/themes`.

### Переход с Grav 1.x на 2.0 {: #migrating-from-grav-1-x-to-2-0 }

Grav 2.0 — это не обновление на месте с 1.x. Минимальная версия PHP, стек vendor, админка и API — всё меняется, поэтому поддерживаемый путь — чистая установка с последующим импортом контента.

Полный процесс описан в главе [Миграция](../../migration/index.md), включая:

- рабочий процесс [автоматизированной миграции](../../migration/assisted-migration/index.md) через плагин Migrate to Grav 2.0
- процедуру [ручной миграции](../../migration/manual-migration/index.md) для сложных конфигураций
- [руководство по обновлению для разработчиков](../../migration/developer-upgrade-guide/index.md) для авторов плагинов и тем

Если вы используете Grav 1.5 или более раннюю версию, сначала обновитесь через GPM до финального релиза 1.7 (`1.7.51`), а затем переходите на 2.0.

### Проверка совместимости плагинов {: #plugin-compatibility-checks }

Grav 2.0 вводит свойство `compatibility:` в файлах `blueprints.yaml` плагинов и тем, объявляющее, с какими мажорными версиями Grav протестирован пакет. Этот флаг читается в двух местах:

- мастер **Migrate to Grav 2.0** при переносе сайта 1.x в подготовленную установку 2.0. Несовместимые пакеты проходят через политику пользователя «пропустить или отключить», с режимами **строгий** и **разрешающий** для обработки пакетов без флага.
- **GPM** при установке или обновлении плагинов на уже мигрированном сайте 2.0. Пакеты без флага совместимости с 2.0 не установятся без ошибок.

Авторы плагинов объявляют совместимость в своём `blueprints.yaml` с помощью свойства `compatibility:`. Подробности см. в разделе [Совместимость плагинов](../../plugins/plugin-compatibility/index.md).

### Обновления Grav CMS {: #grav-cms-updates }

Предпочтительный способ обновления Grav — использовать **GPM (менеджер пакетов Grav)**. Всё, что нужно, — перейти в корень вашего сайта Grav и набрать:

```bash
bin/gpm selfupgrade -f
```

> [!NOTE] Примечание
> **Совет:** больше информации о команде можно найти в разделе [Команды GPM > Self-upgrade](../../cli-console/grav-cli-gpm/index.md#self-upgrade).

### Обновления плагинов и тем {: #plugin-and-theme-updates }

Плагины и темы можно поддерживать в актуальном состоянии, выполнив следующую команду из корня вашего сайта Grav:

```bash
bin/gpm update
```

> [!NOTE] Примечание
> **Совет:** больше информации о команде можно найти в разделе [Команды GPM > Update](../../cli-console/grav-cli-gpm/index.md#update).
