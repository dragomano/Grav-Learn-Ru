# Базовый урок {: #basic-tutorial }

Предполагая, что вы успешно [установили Grav](../installation/index.md) по инструкциям из предыдущей главы, продолжим и немного поиграем с Grav, чтобы вы освоились.

Поскольку Grav не требует базы данных, с ним довольно легко работать, не беспокоясь о конфликтах между установкой Grav и каким-либо другим важным источником данных. Если что-то пойдёт не так, обычно всё можно легко восстановить.

## Основы работы с контентом {: #content-basics }

Для начала познакомимся с тем, где Grav хранит контент. Мы подробнее рассмотрим это в [следующей главе](../folder-structure/index.md), но пока достаточно знать, что весь пользовательский контент хранится в папке `user/pages/` вашей установки Grav.

Сейчас в папке pages есть две папки: первая называется `01.home`, вторая — `02.typography`. Часть `01.` в имени папки необязательна, но даёт пару полезных возможностей.

Во-первых, она позволяет явно задать порядок страниц. Например, `01` будет идти перед `02`, а `00` — перед `01`.

Кроме того, числовая часть имени папки явно сообщает Grav, что эта страница должна быть видна в меню. Важно отметить, что числовая часть вместе с точкой удаляется из URL.

## Настройка главной страницы {: #home-page-configuration }

В файле `user/config/system.yaml` есть параметр, задающий расположение __главной страницы__, то есть куда Grav указывает при обращении к корню сайта: `http://my-site.example`.

Если вы посмотрите этот файл конфигурации в своей установке, то увидите, что он уже указывает на псевдоним `/home`. В этом примере мы можем оставить всё как есть.

## Редактирование страниц {: #page-editing }

Страницы в **Grav** пишутся в синтаксисе **Markdown**. Markdown — это синтаксис форматирования обычного текста, который компьютер может легко разобрать и преобразовать в HTML. Он использует простые текстовые символы для обозначения оформления (например, **жирный**, _курсив_, заголовки, списки и т. д.), поэтому писать легко, не зная всех сложностей HTML. К преимуществам Markdown относятся меньшая вероятность ошибок, читаемость, простота изучения и использования и т. д.

Вы можете прочитать [подробное описание доступного синтаксиса](../../content/markdown/index.md) с примерами в документации, но пока просто следуйте за нами.

Откройте главную страницу в своём текстовом редакторе. Файл, который управляет главной страницей, находится в папке `user/pages/01.home/` и называется `default.md`. Весь создаваемый вами контент будет создаваться в папке `user/pages/` вашей установки Grav.

Когда вы откроете страницу в текстовом редакторе, содержимое будет выглядеть примерно так:

```yaml linenums="1"
---
title: Home
body_classes: title-center title-h1h2
---
```

```markdown linenums="1"
# Say Hello to Grav!
## installation successful...

Congratulations! You have installed the **Base Grav Package** that provides a **simple page** and the default **Quark** theme to get you started.

> [!CAUTION]
> If you see a **404 Error** when you click I15 in the menu, please refer to the [troubleshooting guide](https://learn.getgrav.org/troubleshooting/page-not-found).
```

Давайте разберём это по частям, чтобы вы увидели, как легко писать на Markdown. То, что находится между маркерами `---`, — это [заголовки страницы](../../content/headers/index.md), и они записаны в простом формате [YAML](../../advanced/yaml/index.md). Этот блок конфигурации, расположенный в файле `.md`, обычно называют **YAML Front Matter** (метаданные страницы в YAML).

```bash linenums="1"
title: Home
body_classes: title-center title-h1h2
```

Этот блок задаёт HTML-тег title для страницы (текст, который вы видите на вкладке браузера). Также к нему можно обратиться из темы через атрибут `page.title`. Есть [несколько стандартных заголовков](../../content/headers/index.md), позволяющих настроить различные параметры страницы. Другой пример — `menu: Something`, который позволяет переопределить текст, отображаемый в качестве названия страницы в меню. По умолчанию Grav использует для меню значение title.

```markdown linenums="1"
# Say Hello to Grav!
## installation successful...
```

Синтаксис `#` (или «решёток») в Markdown обозначает заголовок. Один `#` с пробелом и текстом после него преобразуется в заголовок `<h1>` в HTML. `##` (двойная решётка) преобразуется в тег `<h2>`. Разумеется, так можно дойти до допустимого в HTML тега `<h6>`, для которого понадобится шесть решёток: `###### My H6 Level Header`.

```markdown linenums="1"
Congratulations! You have installed the **Base Grav Package** that provides a **simple page** and the default **Quark** theme to get you started.
```

Это простой абзац, который при преобразовании в HTML был бы обёрнут в обычные теги `<p>`. Маркеры `**` обозначают жирный текст, или `<strong>` (ранее `<b>`) в HTML. Курсив обозначается обёртыванием текста в маркеры `_`.

```markdown linenums="1"
> [!CAUTION]
> If you see a **404 Error** when you click I33 in the menu, please refer to the [troubleshooting guide](https://learn.getgrav.org/troubleshooting/page-not-found).
```

В этом разделе используется специальная фича Markdown, предоставляемая включённым плагином `markdown-notices`. Он позволяет создавать простые уведомления, предваряя абзац текста несколькими символами `!` (восклицательный знак) — от `!` до `!!!!`.

Этот обзор должен дать вам несколько ключевых подсказок для написания Markdown, но для полного понимания ознакомьтесь с нашим [подробным объяснением](../../content/markdown/index.md).

> [!CAUTION] Внимание
> Убедитесь, что вы сохраняете файлы `.md` в кодировке `UTF8`. Это гарантирует правильную работу со специальными символами конкретных языков.

## Добавление новой страницы {: #adding-a-new-page }

Создать новую страницу в **Grav** очень просто. Просто выполните следующие шаги:

1. Перейдите в папку со страницами `user/pages/` и создайте новую папку. В этом примере мы воспользуемся [явным порядком по умолчанию](https://learn.getgrav.org/content/content-pages) и назовём папку `03.mypage`.
2. Запустите текстовый редактор, создайте новый файл и вставьте в него следующий пример кода:

```yaml linenums="1"
---
title: My New Page
---
```

```markdown linenums="1"
# My New Page!

This is the body of **my new page** and I can easily use _Markdown_ syntax here.
```

3. Сохраните этот файл в папку `user/pages/03.mypage/` под именем `default.md`. Это скажет **Grav**, что страницу нужно отрендерить с помощью шаблона **default** в текущей теме: `user/themes/quark/templates/default.html.twig`.
4. Вот и всё! Перезагрузите браузер, чтобы увидеть новую страницу в меню вверху.

Страница автоматически появится в меню после пункта **«Typography»**. Если вы хотите изменить название, отображаемое в меню, добавьте `menu: My Page` между дефисами в метаданных страницы.

**Поздравляем**, вы успешно создали новую страницу в Grav. С Grav можно сделать гораздо больше, поэтому продолжайте читать, чтобы узнать о более продвинутых возможностях и подробных фичах.

> [!CAUTION] Внимание
> Если у вас возникли проблемы с доступом к этой новой странице, возможно, у вас отсутствует файл `.htaccess` (только для веб-сервера Apache) или вам нужно отредактировать команду `RewriteBase` в файле `.htaccess`. Обратитесь к главе [Решение проблем](../../troubleshooting/index.md) за дополнительной информацией.
