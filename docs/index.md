# Документация Grav

Grav — это быстрая, простая и гибкая файловая CMS. Этот сайт документирует **Grav 2.0** и сохраняет те части документации Grav 1.7, которые ещё не переписаны для 2.0, как и официальная документация.

> Впервые в Grav? Начните с [Что такое Grav?](basics/what-is-grav/index.md) и [Установка](basics/installation/index.md).
