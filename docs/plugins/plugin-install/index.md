# Установка плагинов

Плагин можно установить одним из трёх способов:

- Способ через **GPM** (Grav Package Manager) устанавливает плагин одной командой в терминале и разрешает его зависимости. Используйте его, если нет причин поступать иначе.
- Способ через **админку** устанавливает плагин с экрана «Плагины» в [Admin Next](../../admin-panel/index.md).
- **Ручной** способ устанавливает плагин из zip-файла — для плагинов, которых нет в репозитории Grav.

В шагах ниже плагин должен сообщить вам **_NAME_** (имя), которое нужно использовать. Это слаг плагина, например `admin2`, `form`, `login`.

## Установка через GPM (предпочтительно)

Из корня установки Grav выполните:

```bash
bin/gpm install NAME
```

Плагин появится в `user/plugins/NAME`. Если он объявляет зависимости, GPM перечислит их и один раз спросит подтверждение перед установкой. Поэтому цепочку редко приходится устанавливать вручную. Например, `bin/gpm install admin2` также установит `api`, `login`, `form`, `email` и `shortcode-core`.

Полезные команды:

```bash
bin/gpm index                # все доступные пакеты с установленной версией
bin/gpm index -i             # только уже установленные
bin/gpm info NAME            # что это за пакет, что ему нужно и какая версия актуальна
bin/gpm update               # обновить всё, для чего есть новая версия
bin/gpm update NAME          # обновить только один пакет
bin/gpm uninstall NAME       # удалить пакет с предупреждением о зависимых
```

> [!NOTE] Примечание
> Для `bin/gpm` нужны расширение PHP `zip` и доступ к внешней сети. Если хостинг блокирует что-то из этого, используйте ручной способ ниже.

## Установка через админку

В [Admin Next](../../admin-panel/index.md) откройте **Плагины** в боковой панели и нажмите **Добавить**. Найдите плагин и нажмите кнопку **Установить**. Зависимости обрабатываются так же, как в командной строке, и вам будет предложено их подтвердить.

На экране «Плагины» также можно включать, отключать, настраивать и обновлять плагин после установки.

## Ручная установка

Скачайте zip-файл плагина, распакуйте его в `user/plugins/` и переименуйте папку в имя плагина, чтобы получилось `user/plugins/NAME`.

После этого проверьте `user/plugins/NAME/blueprints.yaml`. В блоке `dependencies` перечислено всё, что ещё нужно плагину, а при ручной установке эти зависимости не скачиваются. Блок `compatibility` сообщает, какие версии Grav поддерживает плагин.

> [!WARNING] Предупреждение
> Плагин, написанный для Grav 1.x, не обязательно будет работать в Grav 2.0, а тот, что подключается к классической админке, точно не будет. О том, что изменилось и как это определить, см. в разделе [Совместимость плагинов](../plugin-compatibility/index.md).

## Очистка кэша

После любого способа установки очистите кэш, чтобы Grav подхватил плагин:

```bash
bin/grav clear
```
