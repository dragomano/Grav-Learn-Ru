# Плагины

Grav полностью расширяется благодаря мощной архитектуре плагинов, позволяющей дополнять ядро и добавлять столько возможностей, сколько нужно.

- **[Основы плагинов](plugin-basics/index.md)** — Grav задуман простым и сфокусированным на работе только со страницами. Идея в том, что сам Grav очень лёгкий и предоставляет ровно столько возможностей, сколько нужно для базовых задач: маршрутизации, компиляции Markdown в HTML, Twig…
