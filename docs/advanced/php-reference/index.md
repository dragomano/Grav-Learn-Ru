# Справочник по PHP

Справочник по классам, интерфейсам и методам PHP API Grav 2.0 генерируется автоматически из исходного кода, поэтому его текст не переводится: описания в нём приведены на языке оригинала, а сигнатуры методов совпадают с кодом Grav.

Полная версия справочника доступна на официальном сайте документации Grav:

**[PHP Reference →](https://learn.getgrav.org/2/advanced/php-reference)**

> [!NOTE] Примечание
> Справочник собирается из ветки Grav 2.x и обновляется вместе с исходным кодом, поэтому на сайте первоисточника всегда представлена актуальная версия.
