# Список контента

`![Вид списка](flex-objects-list.png?width=2030&classes=shadow)`

**Список контента** обычно содержит постраничный перечень вашего контента, но некоторые директории, например **[Pages](https://learn.getgrav.org/17/admin-panel/page)**, могут иметь сильно настроенный внешний вид.

Здесь можно создавать, редактировать и удалять контент. На странице также есть мощные инструменты для **поиска** и **сортировки** элементов.

## Элементы управления

В верхней части страницы находятся элементы административного управления. Они могут различаться в зависимости от **типа Flex**, но вот список самых распространённых:

- **Back**: вернуться на уровень выше, обычно в [**Dashboard**](https://learn.getgrav.org/17/admin-panel/dashboard) или к **[списку директории](../index.md#the-list-view)**
- **Export**: экспортировать контент в файл, обычно CSV
- **Add**: добавить новый элемент контента
- [**Configuration**](../configuration/index.md): изменить настройки директории

## Навигация

- **Filter**: текстовое поле для поиска
- **Display Number**: число отображаемых объектов
- **Ordering**: нажмите на заголовки колонок, чтобы изменить порядок
- **Pagination**: быстрый переход между объектами

## Отдельная строка

- **Columns**: колонки, специфичные для типа, для быстрого обзора объектов
- **Actions**: действия для отдельного объекта, обычно: **Preview**, **Edit**, **Delete**…
