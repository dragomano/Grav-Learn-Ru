# Начало работы

В этом разделе пошагово рассказано, как быстро включить существующую **директорию Flex** и как отобразить её в админке Grav. В примерах мы для демонстрации используем **директорию Flex Contacts**, которая входит в комплект **плагина Flex Objects**.

## Включение директории

Чтобы включить пользовательскую **директорию Flex**, перейдите в **Plugins** > **Flex Objects** в админке Grav.

Ближе к низу страницы вы увидите настройку **Directories**. В ней перечислены все обнаруженные в вашем проекте **директории Flex**.

`![Настройки плагина](flex-objects-options.png?width=2030&classes=shadow)`

Найдите директории, которые хотите включить, и убедитесь, что отмечен параметр **Enabled**.

Для демонстрации включим директорию **Contacts** и нажмём **Save** в верхней части страницы.

После перезагрузки страницы в меню админки Grav должен появиться новый пункт **Contacts**.

## Установка тестовых данных (необязательно)

Для нашего примера мы предполагаем, что вы скопировали тестовый набор данных для директории **Contacts**:

```shell
$ cp user/plugins/flex-objects/data/flex-objects/contacts.json user/data/flex-objects/contacts.json
```

## Создание страницы

Перейдите в **[Pages](https://learn.getgrav.org/17/admin-panel/page)** и [добавьте новую страницу](https://learn.getgrav.org/17/admin-panel/page##adding-new-pages). Введите следующие значения:

- **Page Title**: `Directory`
- **Page Template**: `Flex-objects`

После этого можно нажать кнопку **Continue**.

В **[продвинутом редакторе контента](../views-edit/index.md)** убедитесь, что во frontmatter указано `flex.directory` со значением `contacts`:

```twig
---
title: Directory
flex:
  directory: contacts
---

# Directory Example
```

Когда страница вас устроит, нажмите **Save**.

> [!WARNING] Предупреждение
> **Совет:** если не указать `Flex Directory`, страница выведет список всех директорий вместо записей из одной директории.
