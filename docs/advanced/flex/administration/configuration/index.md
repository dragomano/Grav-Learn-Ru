# Конфигурация

В **конфигурации** собраны общие настройки **директории Flex**.

Эти настройки обычно используются для изменения поведения директории, задания значений по умолчанию для объектов или изменения рендеринга макетов.

> [!CAUTION] Внимание
> Настройки в каждой директории разные; этот документ содержит только общие настройки, которые есть в любой директории.

#### Элементы управления

В верхней части страницы находятся элементы административного управления.

- **Back**: вернуться к **[списку контента](../views-list/index.md)**
- **Save**: сохранить конфигурацию и вернуться к **[списку контента](../views-list/index.md)**

### Вкладка кэширования

| Параметр                        | Описание |
| :-----                        | :----- |
| **Enable Index Caching** | Кэширование индекса ускоряет поиск, создавая временные индексы для запросов. |
| **Index Cache Lifetime (seconds)** | Время жизни кэша индекса в секундах. |
| **Enable Object Caching** | Кэширование объектов ускоряет загрузку данных объектов и изображений. |
| **Object Cache Lifetime (seconds)** | Время жизни кэша объектов в секундах. |
| **Enable Render Caching** | Кэширование рендеринга ускоряет вывод контента за счёт кэширования итогового HTML. |
| **Render Cache Lifetime (seconds)** | Время жизни кэша рендеринга в секундах. |

Если отрендеренный HTML содержит динамический контент, кэш рендеринга можно отключить из шаблона Twig с помощью ```{% do block.disableCache() %}```.
